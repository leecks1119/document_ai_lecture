# Streamlit 앱 구현 요청 예시

```text
목표:
파일 입력, 처리 버튼, 판독 원문, JSON, 검증 결과, Excel 다운로드가 있는
Streamlit 앱 코드를 만들어줘.

맥락:
한 번에 영수증 한 장을 처리하며 OCR·구조화·검증 함수는 이미 준비돼 있어.
모든 코드는 Google Colab에서 파일로 만들고 AppTest로 검사할 거야.

제약조건:
- Streamlit 1.60.0을 사용해.
- CSS, 테마, 데이터베이스, 로그인, 배포 코드는 추가하지 마.
- 실제 처리와 준비 결과를 화면에서 구분해.
- 검증 오류가 있으면 Excel 다운로드를 표시하지 마.
- 원본과 추출값을 대조했다는 사람의 승인 전에는 Excel 다운로드를 표시하지 마.

완료 기준:
- 파일 입력은 한 장만 받는다.
- 업로드 처리와 준비 결과 실행을 구분한다.
- 검증 통과와 사람 승인을 모두 확인한 뒤에만 Excel을 내려받는다.
- `streamlit.testing.v1.AppTest`에서 예외 없이 실행된다.
```
