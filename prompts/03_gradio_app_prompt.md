# Gradio 앱 구현 프롬프트

```text
목표:
파일 입력, 처리 버튼, 상태, OCR 텍스트, JSON 결과를 가진 Gradio Blocks 화면을 만들어줘.

맥락:
초보자용 합성 영수증 실습이며 처리 함수는 이미 있어.

제약조건:
- Gradio만 사용해.
- CSS, 테마, 데이터베이스, 로그인, 배포 코드는 추가하지 마.
- mock 결과에는 항상 'MOCK 결과'라고 표시해.
- 업로드 오류 뒤 자동으로 샘플 JSON을 표시하지 마.

완료 기준:
처리 버튼과 샘플 버튼이 서로 다른 함수에 연결되고 화면을 실행하지 않아도 함수를 직접 테스트할 수 있어야 해.
```
