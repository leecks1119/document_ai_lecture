# 기존 교재 7. 다중 OCR 앙상블

- 원본: [다중 OCR 조합, 앙상블 기법](https://app.notion.com/p/282707c7ae758182bd96fb5959b33e81)
- Notion 조회 시점의 최종 수정일: 2025-10-04

## 학습 목표

- PaddleOCR, Tesseract, EasyOCR 동시 실행
- 투표 기반과 가중치 기반 결과 통합
- 앙상블 성능 평가

## 코드 자산

### `MultiOCREngine`

- 세 OCR 엔진 초기화
- 엔진별 텍스트와 신뢰도를 공통 딕셔너리 형태로 반환

### `VotingEnsemble`

- `difflib.SequenceMatcher`로 유사 텍스트 그룹화
- 그룹별 다수결 결과와 투표 수 계산

### `WeightedEnsemble`

- 엔진별 고정 가중치 적용
- 신뢰도와 엔진 가중치를 곱해 최종 후보 선택

### `EnsembleEvaluator`

- Ground Truth와 결과의 문자열 유사도 비교
- 개별 엔진과 앙상블의 정확도·평균 신뢰도 비교

## 문제점

- 서로 다른 엔진의 바운딩 박스와 읽기 순서를 먼저 정렬하지 않아 같은 위치의 텍스트라는 보장이 없음
- 엔진별 신뢰도는 같은 척도로 보정되지 않았는데 직접 가중 합산
- 다수결 그룹의 `confidence` 계산이 실제 신뢰도를 의미하지 않음
- 고정 가중치 0.4, 0.35, 0.25에 근거가 없음
- 설치 시간, 메모리와 모델 다운로드 부담이 큼

## 개편 판단

- “오류 시 다른 경로로 재시도”라는 설계 아이디어만 보존
- 8시간 입문 과정에서는 다중 OCR 설치와 앙상블 구현 제외
- OCR 실패 시 mock 결과를 사용하는 단순하고 안정적인 분기로 교체
- 앙상블은 후속 심화 과정 주제로 안내

판정: **본 과정 제외, 심화 참고 자료**
