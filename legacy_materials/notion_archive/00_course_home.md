# 기존 Notion 강의 홈

- 원본: [Document AI 강의](https://app.notion.com/p/281707c7ae7581beb748feca63ac4e16)
- Notion 조회 시점의 최종 수정일: 2026-06-03
- 역할: 과정 소개, 강사 소개, 사전 설문, OCR 시장·기술 질의응답, 하위 교재 목록

## 과정 운영 방향

- 총 8시간 실습 중심 과정
- “자기주도적 호기심 해소” 방식
- 이론 10%, 실습 90%, 상용 AI 적극 활용
- 실습 코드와 샘플 데이터는 강의 진행에 따라 순차 업데이트

## 강사 소개에 포함된 내용

- 삼성SDS 보안 PM 및 AI-SOC 솔루션 업무 리딩
- 보안 로그 분석, 위협 탐지, 자동화 시스템 구축 경험
- LLM 기반 서비스, SIEM·보안 데이터 파이프라인, AWS 기반 보안 SaaS 전문성
- Agentic AI 기반 EDR 정오탐 분석 경험

강사 이력은 교재 본문과 분리해 과정 소개 페이지 또는 강사용 자료에서 관리하는 것이 적합하다.

설문은 표 구조화와 웹 도구 구현 수요가 높다는 근거로 활용할 수 있다. 다만 조사 인원, 조사 시점, 질문 방식이 기록되지 않아 일반화된 통계로 인용하면 안 된다.

## 기존 질의응답 주제

### 국내 업체와 OCR 솔루션

페이지에는 업스테이지, 사이냅소프트, 트웰브랩스, 유니닥스, 퓨리오사AI를 국내 관련 기업으로 소개하고 다음 제품군을 분류했다.

- 오픈소스: Tesseract, EasyOCR, TrOCR, Donut
- 클라우드 API: Google Cloud Vision, AWS Textract, Azure Document Intelligence, Naver CLOVA OCR
- 상용·특화: DEEP OCR+, Alchera ID OCR, Textscope Reader, ABBYY FineReader, Synap OCR, Kakao OCR

“국내 선두”, “글로벌 경쟁력”, 제품별 내부 아키텍처와 같은 표현은 근거가 연결되어 있지 않아 새 교재에는 검증 없이 사용하지 않는다.

### OCR 도입 고려사항

- 이미지 품질과 노이즈 강건성
- 한글·필기체·다국어 지원
- 처리 속도와 비용
- 클라우드와 온프레미스 선택
- API와 설치형 배포 방식
- 개인정보 보호와 마스킹
- PDF, Word, 이미지 등 입력 형식 지원

이 체크리스트는 1교시와 8교시의 업무 적용 판단 자료로 재사용 가치가 높다.

### 그림과 표 처리

- 그림: 영역 탐지 → 추출 → 캡션 또는 설명 생성
- 표: 레이아웃 파싱 → 셀 매핑 → JSON·CSV·Markdown 구조화
- 전통 방식: 선 검출, OCR, 정규식과 수동 후처리
- 최신 방식으로 소개된 항목: LayoutLMv3, Table Transformer, Donut, TILT, VLM

페이지의 오류율, 속도 배수, 정확도 향상 수치는 출처가 없으므로 폐기하고 처리 단계 개념만 활용한다.

### 분할 문서

문서 분할 문제를 경계 탐지와 레이아웃 분석 관점에서 설명하고 있지만, 작성자가 실제 적용 경험이 없다고 명시했다. 새 입문 과정에서는 개념 소개 수준으로만 다룬다.

## 포함된 교재

기존 1~11번 교재, Document AI 활용 아이디어, 2026 리뉴얼 커리큘럼으로 연결된다. Notion 검색 결과 최상위 페이지를 포함해 총 14개 페이지가 확인됐으며 추가 중첩 교재는 없었다.

## 개편 판단

- 기술·제품 목록: 2026년 공식 자료로 전면 재검증

- 강사 소개: 교재 본문이 아닌 과정 홈으로 분리
