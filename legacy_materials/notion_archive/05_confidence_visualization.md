# 기존 교재 5. 신뢰도 측정과 결과 시각화

- 원본: [신뢰도 측정, 결과 시각화](https://app.notion.com/p/282707c7ae7581a3b459cddabb372ea2)
- Notion 조회 시점의 최종 수정일: 2025-10-15
- 연결 실습: `notebooks/Lab05_신뢰도측정.ipynb`

## 학습 목표

- OCR 신뢰도 분석
- 바운딩 박스 시각화
- 저신뢰도 영역 식별과 재처리

## 실습 흐름

1. 깨끗한 이미지와 Gaussian Blur·랜덤 노이즈를 적용한 이미지 생성
2. Tesseract로 단어별 텍스트와 신뢰도 수집
3. 평균·최소·최대 신뢰도와 저신뢰도 단어 개수 출력
4. 신뢰도 분포 히스토그램 비교
5. 임계값보다 낮은 단어의 텍스트와 바운딩 박스 기록
6. 재촬영, 전처리 또는 다른 처리 경로 안내

## 코드 자산

- `analyze_confidence`
- 깨끗한 이미지와 저품질 이미지 생성 코드
- 신뢰도 히스토그램
- `quality_check(image_path, threshold)`
- 저신뢰도 단어 목록과 위치 반환

## 기존 운영 규칙

- 90% 이상: 자동 승인
- 70~90%: 선택 검증
- 70% 미만: 필수 검증 또는 재처리

이 값은 범용 표준이 아니다. AWS 공식 자료처럼 업무 민감도에 따라 기준을 설정해야 하며, 금액·계약·개인정보는 높은 신뢰도라도 형식과 원문을 추가 검증해야 한다.

## 개편 판단

- 깨끗한 문서와 저품질 문서 비교는 2교시 핵심 데모로 재사용
- 신호등 시각화는 1교시의 사람 검토 개념과 7교시 검증 UI에 재사용
- 전체 히스토그램 실습은 시간상 선택 과제로 이동
- 평균 신뢰도만으로 자동 승인하는 코드는 사용하지 않음

판정: **시각 자료와 품질 분기 개념은 높은 재사용 가치**
