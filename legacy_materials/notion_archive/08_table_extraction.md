# 기존 교재 8. 표 검출 및 데이터 추출

- 원본: [표 검출 및 데이터 추출](https://app.notion.com/p/282707c7ae75812b98adf24b5f2b243f)
- Notion 조회 시점의 최종 수정일: 2025-10-04

## 학습 목표

- 표 영역 검출
- 셀 단위 OCR
- 행·열 구조 파악
- DataFrame 변환
- 병합 셀 처리

## 코드 자산

### `TableDetector`

- 그레이스케일과 Otsu 이진화
- 수평·수직 모폴로지 커널로 선 검출
- 선 마스크 결합
- contour 면적으로 표 후보 필터링

### `TableDataExtractor`

- contour의 바운딩 박스로 셀 이미지 자르기
- 각 셀에 PaddleOCR 적용
- x, y, width, height, text를 DataFrame으로 저장
- y 좌표 구간과 x 정렬로 행·열 번호 부여

### `TableToDataFrame`

- `pivot`으로 행·열 구조 생성
- 첫 행을 헤더로 사용

### `MergedCellHandler`

- 평균 셀 크기보다 큰 셀을 병합 셀로 추정
- 추정한 행·열 span을 테이블에 반영

## 재사용 가치

- 표는 단순한 텍스트 모음이 아니라 행·열 관계를 보존해야 한다는 설명
- 좌표를 이용해 읽기 순서와 셀 관계를 구성하는 개념
- 최종 결과를 DataFrame과 CSV로 변환하는 흐름

## 문제점

- contour 하나가 셀인지 표 전체인지 구분하는 로직이 충분하지 않음
- y 좌표를 20개 구간으로 고정한 방식은 표 크기에 따라 실패
- 평균 크기만으로 병합 셀을 판별하는 방식은 신뢰하기 어려움
- 테두리가 없거나 복잡한 비정형 표에 적용하기 어려움
- 초급자가 1시간 안에 안정적으로 완성하기 어려움

## 개편 판단

- 3교시에서 키-값·표·반복 항목의 차이를 설명할 때 시각 자료로 활용
- 표 검출 알고리즘 구현은 제외
- 제공된 OCR/mock 결과를 행 단위로 정리하는 실습으로 단순화
- 7교시 DataFrame과 CSV 변환으로 연결

판정: **구조 개념은 재사용, 검출 구현은 심화 참고**
