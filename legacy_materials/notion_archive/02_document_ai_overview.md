# 기존 교재 2. Document AI 개요와 AI 기술표

- 원본: [Document AI, 한 눈에 보는 AI 기술표](https://app.notion.com/p/282707c7ae75819da13df1aa1a3dd398)
- Notion 조회 시점의 최종 수정일: 2025-10-15

## 학습 목표

- Document AI를 제3자에게 설명할 수 있다.

## 핵심 정의

- 비정형 문서: PDF, 스캔 이미지, 사진
- 구조화 결과: JSON, CSV, 데이터베이스
- 결합 기술: OCR, Computer Vision, NLP, LLM
- Document AI를 단일 모델이 아니라 여러 기술을 연결한 처리 체계로 설명

## 포함된 시각 자료

1. 전통 OCR·템플릿에서 딥러닝 OCR·레이아웃 분석·멀티모달 LLM으로 이어지는 진화 경로
2. Computer Vision, NLP, LLM으로 나눈 Document AI 핵심 영역
3. 문서 수집 → 콘텐츠 추출 → 지능형 처리의 3단계 파이프라인
4. 입력·처리·출력·모니터링으로 구성한 전체 시스템 아키텍처

Mermaid 원본 구조는 유용하지만 “과거·현재·미래” 연도와 특정 모델 표기는 2026년 기준으로 다시 작성해야 한다.

## 기술 비교 내용

- Computer Vision: 전처리, OCR, 레이아웃 탐지
- NLP: 정보 추출, 문서 분류, 요약
- Multimodal AI: 이미지와 텍스트의 결합 처리
- Generative AI: 오류 보정, 의미 파악, 맥락 추론
- Speech AI, 강화학습, 추천 시스템은 Document AI 핵심 범위가 아니라고 구분

## 기존 처리 단계

### 문서 수집

- 파일 포맷 변환
- 메타데이터 추출
- 품질 검사와 분류
- 배치 처리 대기열

### 콘텐츠 추출

- OCR
- 레이아웃 탐지
- 표 추출
- 이미지 전처리

### 지능형 처리

- NER
- 문서 분류
- 키-값 추출
- 의미와 관계 분석
- 규칙 기반 검증과 비즈니스 로직

### 결과

- JSON 또는 XML
- 검증된 필드 값
- 신뢰도 점수
- 메타데이터와 추적 정보

## 재검증이 필요한 주장

- Computer Vision 40%, NLP 30%, Multimodal AI 20%, Generative AI 10% 구성비
- 수작업 대비 70~85% 시간 단축
- 페이지당 1~3초
- OCR 95% 이상, 데이터 추출 90% 이상
- 99.9% 가용성
- 생성형 AI를 단순 “보정 기술”로 한정한 설명

## 개편 판단

- Document AI 정의와 비정형→구조화 비교: 1교시 핵심 자료로 재사용
- 3단계 파이프라인: 새 과정의 업로드→OCR→JSON→검증→CSV로 단순화
- 시스템 아키텍처와 모니터링: 8시간 입문 과정에서는 제외
- 출처 없는 구성비·성능 수치: 폐기
- 인간 검토 필요성: 공식 근거를 추가해 강화

판정: **개념과 다이어그램 구조는 재사용, 수치와 기술표는 전면 검증**
