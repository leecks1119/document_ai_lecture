## 현재 저장소 커리큘럼과의 관계

이 페이지는 현재 `docs/curriculum.md`의 직접적인 기반이다. 핵심 흐름과 산출물은 유지됐으며 이후 결정으로 다음 항목이 변경됐다.

- 개발 도구: Cursor 중심에서 Codex 중심으로 변경
- 웹 프레임워크: Streamlit 중심안에서 Gradio 권장, Streamlit 대체안으로 변경
- OCR 실패 시 mock 결과를 사용하는 대체 경로 명시
- 실제 API 키 없이도 JSON 구조화 실습 가능
- 개인정보와 사람 검토 원칙 강화

## 개편 판단
