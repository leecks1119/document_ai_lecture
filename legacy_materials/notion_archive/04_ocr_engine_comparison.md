# 기존 교재 4. OCR 엔진 비교

- 원본: [이미지에서 텍스트 추출](https://app.notion.com/p/282707c7ae7581e584abf3b446733b75)
- Notion 조회 시점의 최종 수정일: 2025-10-15
- 연결 실습: `notebooks/Lab04_OCR엔진비교.ipynb`

## 학습 목표

- OCR 엔진으로 이미지 텍스트 추출
- 엔진별 성능 비교
- 정확도, 처리 시간, 신뢰도 측정

## 비교 대상

- Tesseract
- PaddleOCR
- EasyOCR
- TrOCR

페이지는 프레임워크, 검출 방식, 인식 모델, 장단점, 지원 언어를 표로 비교한다. 세부 모델명과 지원 범위는 버전 변화가 크므로 최신 공식 문서로 재검증해야 한다.

## 실습 흐름

1. Tesseract, PaddleOCR, EasyOCR 설치
2. 한글 폰트 설치
3. 한글·영어 혼합 계약서 형태의 가상 이미지 생성
4. 동일 이미지에 세 엔진 실행
5. Levenshtein 편집거리로 문자 단위 유사도 계산
6. 정확도·처리 시간·신뢰도 막대그래프 비교
7. 엔진별 추천 시나리오 토론

## 코드·개념 자산

- `pytesseract.image_to_string`과 `image_to_data`
- PaddleOCR의 인식 텍스트와 평균 신뢰도
- EasyOCR `readtext`
- 공백과 줄바꿈을 제거한 편집거리 기반 비교 함수
- Ground Truth와 예측값을 비교하는 평가 개념

## 문제점

- 예시 정확도와 처리 시간은 실제 실행 결과가 아닌 고정 출력
- “최고 엔진” 판단이 한 장의 생성 이미지에 의존
- 엔진별 신뢰도 정의가 달라 단순 평균 비교가 부정확할 수 있음
- 세 엔진 설치는 초급 8시간 과정의 환경 실패 가능성을 크게 높임
- 샘플에 실명과 실제 회사처럼 보이는 표현이 포함됨

## 개편 판단

- 편집거리와 Ground Truth 개념은 강사용 확장 자료로 보존
- 본 과정은 PaddleOCR 또는 EasyOCR 하나와 mock 모드만 사용
- 엔진 비교는 2교시의 5분 개념 표로 축소
- 세 엔진 설치와 전체 벤치마크는 선택 심화 자료로 이동

판정: **비교 관점은 재사용, 다중 엔진 실습은 본 과정에서 제외**
