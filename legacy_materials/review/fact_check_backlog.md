## P2. 설명 개선

- “AI가 문서를 이해한다”는 표현 대신 텍스트·위치·문맥 패턴으로 필요한 값을 예측한다고 설명
- 신뢰도는 정답 보장이 아니라 검토 우선순위를 정하는 신호라고 설명
- 전처리는 항상 정확도를 올리는 것이 아니며 원본과 비교해야 함을 명시
- 정규식, 전문 문서 모델, 생성형 AI의 장단점을 구분
- OCR 엔진별 신뢰도 점수를 직접 비교하지 않음
- 가상 문서에는 실제 회사명, 실명, 전화번호, 주민등록번호를 넣지 않음
- 외부 API로 문서를 보낼 때 보안과 개인정보 확인 단계를 포함

## 완료 조건

- 모든 수치에 출처나 “가상 예시” 표시가 있다.
- 모든 설치·실행 코드는 Python 3.12.9에서 검증됐다.
- API 키 없이도 동일한 학습 목표를 달성할 수 있다.
- 샘플 문서와 출력에 실제 개인정보가 없다.
- 실패 시 교육생이 다음 단계로 진행할 수 있는 대체 경로가 있다.
