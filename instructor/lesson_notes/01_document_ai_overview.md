# 1교시 강사 노트

## 전달할 한 문장

문서 자동화는 모델 한 번 실행이 아니라 목표·추출·검증·사람 확인·업무 연결·개선의 과정이다.

## 60분 운영

| 구간 | 시간 | 강사 행동 |
| --- | ---: | --- |
| 문제와 완성 결과 | 0~7분 | 원본 영수증과 완성 Excel을 비교 |
| 다섯 용어 | 7~23분 | OCR·Multimodal AI·VLM·Document AI·IDP 경계 설명 |
| 0~12 전체 지도 | 23~30분 | 암기 목록이 아닌 참조 지도라고 강조 |
| 안내형 실습 | 30~48분 | 원문·정규화 값·근거·검증·결정 추적 |
| 비교와 복구 | 48~56분 | 준비 결과 표시와 원본 대조 확인 |
| 정리 | 56~60분 | 2교시 실제 OCR로 연결 |

## 질문과 복구 지점

- “OCR 신뢰도가 높으면 왜 바로 승인할 수 없을까요?”
- `AUTO_ACCEPT` 임계값은 회사 정책으로 정하는 값이며 이번 입문 실습에서는 결정하지 않는다.
- 학생에게는 공개 샘플의 출처·라이선스만 설명하고 상세 검증은 `docs/public_receipt_datasets.md`를 참고한다.
