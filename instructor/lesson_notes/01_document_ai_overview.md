# 1교시 강사 노트

## 전달할 한 문장

같은 영수증을 보더라도 OCR은 글자와 위치를 읽고, VLM은 구조 초안을 만들며, Document AI는 근거와 규칙으로 결과를 검증한다. 실제 업무에서는 사람 승인과 시스템 연결까지 필요하다.

## 이 실습에서 반드시 일어나야 할 경험

수강생이 파일명이나 정의를 암기하는 것으로 끝내지 않는다. 한 장의 영수증에서 다음 네 장면을 직접 확인해야 한다.

1. 실제 PP-OCRv5 결과에서 높은 신뢰도의 오인식을 찾는다.
2. 구조가 자연스러운 VLM 초안에서도 잘못된 합계를 찾는다.
3. 품목 합계와 원본 근거 검사가 오류를 잡는 모습을 본다.
4. 검증 통과와 사람 승인이 서로 다른 조건임을 확인한다.

## 60분 운영

| 시간 | 수강생 행동 | 강사가 확인할 장면 |
| ---: | --- | --- |
| 0~5 | 원본 영수증에서 상호명·날짜·품목 수·합계를 찾음 | AI 결과보다 원본을 먼저 봄 |
| 5~17 | 실제 PP-OCRv5 사각형과 판독 표를 원본과 비교 | `이태리쉽!`, `639,094` 오인식 지목 |
| 17~27 | OCR 검토 질문을 직접 채움 | 신뢰도와 업무 승인을 구분 |
| 27~36 | VLM 구조 초안과 품목 표를 확인 | 품목 합계 76,000원과 초안 합계 16,000원 비교 |
| 36~47 | 검증 코드를 실행하고 합계·근거를 수정 | 수정 전 오류 3개, 수정 후 통과 |
| 47~53 | 승인 전·후 저장 상태를 비교 | 검증 통과만으로 Excel을 만들지 않음 |
| 53~58 | 다섯 개 상황을 기술 개념과 연결 | OCR·멀티모달 AI·VLM·Document AI·IDP 구분 |
| 58~60 | 자신의 말로 차이를 설명 | 2교시 실제 OCR 실행으로 연결 |

## 시작할 때 그대로 말하기

> “오늘은 기술 이름을 외우지 않습니다. 같은 영수증의 결과가 기술마다 어떻게 달라지는지 직접 보고, 잘못된 값을 찾아 고쳐 보겠습니다.”

> “OCR 신뢰도가 높아도 글자가 틀릴 수 있고, VLM이 만든 JSON이 보기 좋아도 합계가 틀릴 수 있습니다. 그 차이를 직접 확인하는 것이 오늘의 목표입니다.”

## 화면별 확인 질문

### 원본 관찰

- 합계는 어디에 있습니까?
- 품목은 모두 몇 줄입니까?
- 사람이 원본을 먼저 읽는 이유는 무엇입니까?

### OCR 결과

- 상호명을 어떻게 읽었습니까?
- 신뢰도 0.830인 과세물품가액은 맞습니까?
- 신뢰도가 업무 정확도나 승인 가능성을 뜻합니까?

정답은 각각 `이태리쉽!`, 아니오, 아니오입니다.

### VLM 구조 초안

- JSON의 항목과 표 모양은 자연스럽습니까?
- 품목 금액을 더하면 얼마입니까?
- 초안의 합계 16,000원을 바로 저장해도 됩니까?

정답은 각각 예, 76,000원, 아니오입니다.

### Document AI 검증

- 어떤 세 가지 이유로 저장이 차단되었습니까?
- 합계만 76,000원으로 고치면 충분합니까?

품목 합계 불일치, 원본 확인값 불일치, 원본 근거 누락이 차단 이유입니다. 합계와 함께 원본 문자열도 기록해야 합니다.

### IDP 운영

- 자동 검증을 통과했는데도 사람 승인이 필요한 이유는 무엇입니까?
- 승인된 결과를 어디에 연결할 수 있습니까?

규칙이 모든 의미 오류를 잡는 것은 아니며, 승인된 결과만 Excel이나 업무 시스템으로 전달합니다.

## 오개념 바로잡기

- “OCR 다음에 항상 VLM을 실행한다” → 두 기술은 문서와 위험에 따라 선택하거나 조합한다.
- “VLM은 OCR의 최신 버전이다” → VLM은 이미지와 언어를 함께 처리하는 모델이며 OCR과 역할이 다르다.
- “Document AI는 특정 모델 이름이다” → 문서를 분류·읽기·구조화·검증하는 기술과 처리 과정이다.
- “검증을 통과하면 자동 승인이다” → 자동 규칙 통과와 사람 승인은 별개의 결정이다.
- “IDP 결과는 Excel 파일이다” → IDP는 접수·예외·검토·시스템 연결·운영까지 포함하는 범위다.

## 진행이 막혔을 때

- 공개 이미지나 OCR 기록 다운로드가 실패하면 Colab 업로드 창이 열린다. 저장소의 비식별 영수증 이미지와 `ppocrv5_recorded_receipt_tokens.json`을 선택한다.
- 빈칸을 어려워하는 수강생은 원본 관찰부터 정답을 열어 따라간다.
- 코드 문법 질문이 길어지면 `TODO` 값만 입력하게 하고 검증 함수는 완성 코드로 실행한다.
- 최소 완료선은 OCR 오인식 두 곳 발견, VLM 합계 오류 발견, 수정 후 검증 통과다.
