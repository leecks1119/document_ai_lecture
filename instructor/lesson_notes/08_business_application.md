# 8교시 강사 노트

## 전달할 한 문장

영수증에서 익힌 흐름을 업무 문서 한 종류·한 장·몇 개 필드로 작게 확장한다.

## 60분 운영

| 시간 | 행동 | 확인할 결과 |
| ---: | --- | --- |
| 0~8 | 견적서·신청서·거래명세서 사진 비교 | 문서 한 종류 선택 |
| 8~23 | 선택 사진에 PaddleOCR-VL 실제 실행 | `실제 모델 실행: True` |
| 23~33 | Markdown에서 제목·표·금액 확인 | 성공·오류 한 곳씩 |
| 33~42 | Excel·Word·PDF·PPT 직접 열기 | 원본 구조 차이 |
| 42~52 | 검토자·자동 저장 중단 조건 작성 | 개인 PoC 카드 |
| 52~57 | 2~3명 결과 공유 | 필드·위험 비교 |
| 57~60 | 강의 핵심 메시지 회수 | `poc_candidate_card.md` |

## 그대로 말하기

> “우리 회사 문서도 같은 흐름으로 시작할 수 있습니다. 먼저 한 종류, 한 장, 몇 개 필드로 줄이세요.”

## 강사 확인

- T4 GPU와 `PaddleOCR-VL-1.6-0.9B` 실제 실행 여부를 확인한다.
- 모델 Markdown의 오류를 지우지 않고 원본과 나란히 보여 준다.
- 점수표 작성보다 검토자와 저장 중단 조건을 구체적으로 정하게 한다.

## 종료 조건

모든 수강생이 업무 문서의 실제 VLM 결과를 확인하고
`poc_candidate_card.md`를 만든다.
