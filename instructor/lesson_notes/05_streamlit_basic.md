# 5교시 강사 노트

## 전달할 한 문장

Streamlit은 Python 처리 함수에 입력·실행·결과 화면을 붙인다.

## 시연·운영

- 공개 터널을 열지 않고 AppTest로 필수 화면 요소를 검사한다.
- AppTest 통과는 UI 코드 실행만 확인하며 추출값 정확성을 보장하지 않는다고 강조한다.
- 버전 고정 이유와 timeout 조정은 학생 본문에서 설명하지 않는다.

## 복구 지점

환경 준비 셀 재실행 → 전체 정답 `app_05.py` 저장 → AppTest 재실행 → 계속 실패하면 처리 함수를 셀에서 직접 호출한다.
