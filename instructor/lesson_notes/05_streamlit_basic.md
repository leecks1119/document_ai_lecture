# 5교시 강사 노트

## 전달할 한 문장

파일 입력·원본 확인·결과 버튼 세 가지만 있어도 작은 업무 화면을 시작할 수 있다.

## 60분 운영

| 시간 | 행동 | 확인할 결과 |
| ---: | --- | --- |
| 0~8 | 완성 화면의 세 영역 설명 | 입력·원본·결과 |
| 8~18 | 앱 제목 한 줄 변경 | 자기 업무 제목 |
| 18~28 | `app_05.py` 생성 | 파일 경로 |
| 28~43 | Colab에서 실제 Streamlit 화면 열기 | iframe 화면 |
| 43~52 | 이미지 업로드·원본 확인·버튼 클릭 | 예제 JSON |
| 52~57 | 실제 모델이 아직 아님을 구분 | 6교시 연결 설명 |
| 57~60 | 결과 저장 | `app_05.py` |

## 그대로 말하기

> “오늘은 웹 개발 문법이 아니라 사용자가 파일을 넣고 결과를 찾는 흐름만 봅니다.”

## 종료 조건

모든 수강생이 앱 화면에서 이미지를 선택하고 원본과 예제 JSON을 확인한다.
