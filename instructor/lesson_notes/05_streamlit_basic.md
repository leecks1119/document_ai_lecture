# 5교시 강사 노트

## 전달할 한 문장

파일을 올렸는데 화면 값이 달라지지 않으면 앱이 연결된 것이 아니다.

## 60분 운영

| 시간 | 행동 | 예상 증거 |
| ---: | --- | --- |
| 0~5 | 완성 앱의 입력·버튼·결과를 가리킴 | 세 영역 |
| 5~10 | 화면과 처리 함수 역할 구분 | 함수는 6교시 |
| 10~18 | 앱 코드 저장 | `app_05.py` |
| 18~32 | 파일 업로드 메시지 확인 | 파일명·bytes |
| 32~42 | 준비 결과 버튼 실행 | mode·원문·JSON |
| 42~48 | 제목·버튼 문구 빈칸 수정 | 자기 화면 |
| 48~53 | AppTest 실행 | 요소 개수 |
| 53~57 | Colab 미리보기 직접 조작 | 클릭 증거 |
| 57~60 | 6교시 함수 연결 예고 | 앱 뼈대 유지 |

## 그대로 말하기

> “파일을 올렸는데 결과가 달라지지 않으면 앱이 연결된 것이 아닙니다.”

## 정상·실패·복구

- 정상: 제목·업로더·버튼, 클릭 후 info·JSON
- 실패: 들여쓰기·Streamlit 설치·저장 순서
- 복구: 설치 셀 → 전체 정답 저장 → AppTest 재실행

공개 터널은 열지 않는다. Colab의 `serve_kernel_port_as_iframe` 미리보기만 사용한다. AppTest 통과는 화면 코드가 실행된다는 뜻이지 추출 정확도를 보장하지 않는다.

## 종료 조건

`app_05.py` 생성, AppTest 통과, Colab 미리보기 조작. 업로드 파일명을 코드가 읽는 `uploaded.getvalue()`와 자신이 바꾼 화면 문구를 찾아야 한다.
