# 6교시 강사 노트

## 전달할 한 문장

현재 이미지에 실제 모델을 실행하고 그 결과가 화면까지 바뀌어야 연동이다.

## 60분 운영

| 시간 | 행동 | 확인할 결과 |
| ---: | --- | --- |
| 0~8 | 입력 이미지 확인 | 실제 모델 입력 파일명 |
| 8~23 | PP-OCRv5 실제 실행 | `실제 모델 실행: True` |
| 23~34 | OCR 원문→업무 JSON 흐름 설명 | 상호명·날짜·총액·품목 수 |
| 34~44 | `app_06.py` 생성·화면 열기 | 실제 OCR 연결 앱 |
| 44~53 | 이미지 업로드·실제 OCR 버튼 클릭 | 실제 처리 성공 문구 |
| 53~57 | 원본과 총액·품목 대조 | 오류 한 곳 찾기 |
| 57~60 | 7교시 검증 연결 | `receipt.json` |

## 그대로 말하기

> “모델이 실행됐다는 것과 값이 맞다는 것은 다른 문제입니다.”

## 금지

- 실제 실행 실패를 예제 결과로 성공처럼 표시하지 않는다.
- 앱 내부 함수 전체를 수강생에게 타이핑시키지 않는다.
- 개인·회사 문서를 승인 없이 업로드하지 않는다.

## 종료 조건

현재 이미지의 실제 OCR 결과와 앱에서 다시 실행한 결과를 확인하고
`receipt.json`, `app_06.py`를 만든다.
