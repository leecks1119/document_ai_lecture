# 3교시 강사 노트

## 전달할 한 문장

OCR이 글자를 읽은 뒤에는 좌표를 이용해 같은 행의 관계를 다시 묶어야 한다.

## 60분 운영

| 시간 | 행동 | 확인할 결과 |
| ---: | --- | --- |
| 0~8 | 원본에서 품목 행 하나를 사람이 먼저 읽기 | 품목명·단가·수량·금액 |
| 8~20 | 현재 이미지에 PP-OCRv5 실제 실행 | `실제 모델 실행: True` |
| 20~32 | 낱말 결과와 좌표 설명 | OCR 영역 수 |
| 32~43 | y좌표로 같은 행, x좌표로 읽기 순서 복원 | 복원된 14개 안팎의 행 |
| 43~52 | 날짜·품목·합계 후보 확인 | 품목 후보 5개 |
| 52~57 | 다른 이미지로 한 번 더 실행 | 깨진 행 한 곳 |
| 57~60 | 결과 저장·4교시 예고 | `clean_receipt.json` |

## 그대로 말하기

> “품목명이 틀린 것은 인식 문제이고, 단가·수량·금액이 다른 줄로 흩어진 것은 구조 문제입니다.”

## 강사 확인

- 실제 Colab에서는 `실제 모델 실행: True`인지 확인한다.
- 저장소 자동검사의 `False`를 실제 실행이라고 설명하지 않는다.
- 정규식을 작성시키지 않는다. 수강생은 모델 결과와 행 복원 결과를 비교한다.

## 종료 조건

수강생이 현재 이미지, OCR 영역 수, 복원된 품목 다섯 행,
`clean_receipt.json`을 확인한다.
