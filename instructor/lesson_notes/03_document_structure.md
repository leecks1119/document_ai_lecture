# 3교시 강사 노트

## 전달할 한 문장

정제는 없는 값을 만드는 일이 아니라 원문을 보존한 채 관계를 다시 묶는 일이다.

## 60분 운영

| 시간 | 행동 | 예상 증거 |
| ---: | --- | --- |
| 0~5 | raw·clean·change 세 값 비교 | 차이 설명 |
| 5~10 | y·x 좌표 읽기 순서, 키-값과 반복 행 설명 | 날짜·품목 구분 |
| 10~15 | 새 런타임에서 이전 파일 업로드 시연 | `PREVIOUS_LESSON` |
| 15~35 | 공간 순서 복원·공백 정리·정규식 빈칸 실행 | 품목 후보 5 |
| 35~43 | `other` 한 줄을 일부러 남김 | 억지 추출 금지 |
| 43~50 | 표 캡처의 행·열 손실 설명 | 셀 관계 답 |
| 50~57 | JSON 확인 | raw 보존 |
| 57~60 | evidence 예고 | 4교시 연결 |

## 그대로 말하기

> “정제는 없는 값을 만드는 일이 아닙니다. 원문을 보존한 채 사람이 읽기 쉽게 고치는 일입니다.”

> “OCR 토큰 배열 순서를 그대로 줄바꿈하면 표가 깨질 수 있습니다. 같은 높이를 먼저 묶고 왼쪽에서 오른쪽으로 놓습니다.”

## 오개념 복구

오타를 문맥으로 자동 수정하려 하면 “원문 보존 → 변경 기록 → 사람 확인” 순서를 다시 보여 준다. 이번 교시에서 확신 없는 문자열은 `other`에 남긴다.

## 복구

새 Colab의 기본값은 `USE_COURSE_EXAMPLE=True`이므로 `COURSE_EXAMPLE`으로
독립 실행된다. 2교시 파일 인계를 시연할 때만 값을 `False`로 바꾸고
`ocr_result.json`을 선택해 `PREVIOUS_LESSON`을 확인한다.

## 종료 조건

`clean_receipt.json`의 `raw_text`, `cleaned_lines`, `change_log`, `groups.items`를 한 곳씩 확인하고 다운로드한다.
