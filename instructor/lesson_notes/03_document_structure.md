# 3교시 강사 노트

## 전달할 한 문장

읽힌 글자를 키-값과 반복 행으로 다시 묶어야 업무 데이터가 된다.

## 시연·운영

- Excel·Word·PPT 원본의 구조, 텍스트 PDF, 표 캡처의 차이는 3분 이내로 비교한다.
- 필수 실습은 영수증의 키-값과 반복 품목 행에만 집중한다.
- 복잡한 표 복원은 완성 결과만 보여 주고 코드를 해설하지 않는다.
- 정제 과정에서 없는 값이 새로 생기지 않도록 `raw_text`와 `change_log`를 함께 확인한다.

## 복구 지점

이전 산출물을 찾지 못하면 `SAMPLE_OCR_TEXT`를 선택하고 같은 정제 함수를 실행한다.
