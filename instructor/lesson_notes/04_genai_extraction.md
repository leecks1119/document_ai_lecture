# 4교시 강사 노트

## 전달할 한 문장

OCR+규칙과 VLM은 서로 다른 초안 경로이며, 어느 쪽도 원본 근거가 없으면 null로 둔다.

## 60분 운영

| 시간 | 행동 | 예상 증거 |
| ---: | --- | --- |
| 0~6 | `clean_receipt.json` 업로드 후 OCR+규칙 기준선 생성 | `PREVIOUS_LESSON` |
| 6~11 | 스키마·근거·불확실성 설명 | 세 질문 |
| 11~18 | 승인된 VLM 시연 1회 또는 녹화 | 실제/준비 라벨 |
| 18~34 | 정제 텍스트→규칙 JSON 실행 | 총액·품목 |
| 34~42 | 준비 VLM 구조 예시와 비교 | `engine=not_executed` |
| 42~48 | evidence·`null` 확인 | 합계 원문 |
| 48~54 | 검토 행동 빈칸 작성 | 자기 답·전체 정답 |
| 54~57 | provenance 확인 | 두 경로 라벨 |
| 57~60 | 앱 결과로 연결 | JSON 2개 |

## 그대로 말하기

> “지금 필수 코드는 OCR 텍스트에 규칙을 적용한 결과입니다. 이것을 VLM 실행이라고 부르지 않습니다.”

> “VLM도 초안입니다. 원본에서 근거를 찾지 못하면 추측하지 말고 null로 둡니다.”

## 시연 중단 기준

모델 실행이 3분을 넘거나 승인된 계정·예산·비식별 조건 중 하나라도 불명확하면 재시도하지 않는다. 준비 결과의 `engine_version`과 `disclaimer`를 보여 준다.

## 확인 질문과 정답

- JSON 문법이 맞으면 값도 맞나? → 아니오
- 날짜가 원문에 없으면? → `null`
- 준비 VLM 예시임을 무엇으로 증명하나? → `engine=not_executed`, provenance, disclaimer

## 종료 조건

`receipt.json`이 OCR+규칙 결과임을 말하고, `vlm_comparison.json`의 준비 예시 라벨을 찾아야 한다. 두 파일의 총액 근거를 비교한다.
