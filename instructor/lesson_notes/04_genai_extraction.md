# 4교시 강사 노트

## 전달할 한 문장

VLM이 만든 구조는 초안이며, 원문 근거와 스키마를 통과해야 업무 데이터가 된다.

## 시연·운영

- PaddleOCR-VL 1.6 또는 승인된 상용 VLM을 비식별 샘플로 한 번만 시연한다.
- API 키·비용·GPU 설정은 강사 화면에서만 관리한다.
- 시연 실패 시 준비된 Markdown을 즉시 사용한다.
- `mock_vlm` 같은 내부 이름은 학생 화면에서 `prepared_vlm` 또는 `준비 결과`로 표현한다.

## 질문과 복구 지점

- “원문에 날짜가 없으면 무엇을 넣을까요?”에 `null`을 답하게 한다.
- 모델 Markdown과 업무 JSON이 다른 이유를 필드명·자료형·필수 여부로 연결한다.
