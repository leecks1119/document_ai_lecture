# 4교시 강사 노트

## 전달할 한 문장

VLM의 JSON은 정답이 아니라 초안이며 원본 근거가 없으면 null로 둔다.

## 60분 운영

| 시간 | 행동 | 예상 증거 |
| ---: | --- | --- |
| 0~6 | `clean_receipt.json` 업로드 후 VLM 중간 결과와 업무 JSON 비교 | `PREVIOUS_LESSON`, 둘이 다름 |
| 6~11 | 스키마·근거·불확실성 설명 | 세 질문 |
| 11~18 | 승인된 VLM 시연 1회 또는 녹화 | 실제/준비 라벨 |
| 18~38 | 정제 텍스트→JSON 실행 | 총액 76000 |
| 38~45 | evidence 찾기 | 합계 원문 |
| 45~50 | 없는 필드 `null` 사례 | 추측 금지 |
| 50~57 | provenance 확인 | not live inference |
| 57~60 | 앱 결과로 연결 | `receipt.json` |

## 그대로 말하기

> “VLM의 JSON은 정답이 아니라 초안입니다. 원본에서 근거를 찾지 못하면 추측하지 말고 null로 둡니다.”

## 시연 중단 기준

모델 실행이 3분을 넘거나 승인된 계정·예산·비식별 조건 중 하나라도 불명확하면 재시도하지 않는다. 준비 결과의 `engine_version`과 `disclaimer`를 보여 준다.

## 확인 질문과 정답

- JSON 문법이 맞으면 값도 맞나? → 아니오
- 날짜가 원문에 없으면? → `null`
- 준비 결과임을 무엇으로 증명하나? → provenance와 source_mode

## 종료 조건

`receipt.json`의 총액, evidence, provenance를 수강생이 직접 찾고 파일을 다운로드해야 한다.
