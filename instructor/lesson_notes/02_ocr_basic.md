# 2교시 강사 노트

## 전달할 한 문장

OCR 결과는 정답이 아니라 원본과 대조할 판독 결과다.

## 60분 운영

| 시간 | 행동 | 예상 증거 |
| ---: | --- | --- |
| 0~5 | `직접 읽었습니다`와 `수업용 예제` 두 화면 비교 | 처리 방식 차이 |
| 5~10 | text·box·confidence 설명 | 세 요소 지목 |
| 10~13 | Colab 외부 클라우드 문장 낭독 | 개인 문서 미업로드 |
| 13~16 | 5개 복구 라인을 1분 간격 시작 | 다운로드 분산 |
| 16~32 | 영수증 직접 OCR 실행 | 직접 실행 성공 또는 오류 |
| 32~38 | bbox에서 상호·날짜·합계 찾기 | 세 영역 |
| 38~45 | 저품질 이미지와 비교 | 숫자 오류 위험 |
| 45~50 | 3분 초과 복구 | 전환 사유 보존 |
| 50~54 | JSON·PNG 확인 | 파일 2개 |
| 54~57 | 원본 대조 빈칸 작성·정답 비교 | 자기 답 보존 |
| 57~60 | ZIP 1개 다운로드·3교시 인계 확인 | `lesson02_ocr_outputs.zip` |

## 그대로 말하기

> “화면의 처리 방식을 먼저 보세요. ‘직접 읽었습니다’는 지금 OCR한 결과이고, ‘수업용 예제’는 현재 사진을 분석한 결과가 아닙니다.”

> “신뢰도는 모델의 자신감이지 결재 도장이 아닙니다.”

## 정상·실패·복구 화면

- 정상: `처리 방식: 지금 이 사진을 OCR로 직접 읽었습니다`, 인식 영역 수
- 실패: 설치·모델 다운로드 오류 그대로
- 예제 사용: `수업용 예제 결과를 불러왔습니다`, 현재 사진 결과가 아니라는 안내, 실패 이유

## 전환 기준

- 개인 3분 초과: 해당 수강생 준비 결과
- 같은 오류 3명: 전원 준비 결과
- 개인정보 문서 발견: 즉시 중지·런타임 폐기

## 종료 조건

`lesson02_ocr_outputs.zip` 안에 `ocr_result.json`, `ocr_boxes.png`가 있는지 확인한다. 직접 OCR 성공 수와 수업용 예제 사용 수를 운영 기록에 남긴다. 개인 영수증 선택 실습은 완전 비식별화 여부를 먼저 확인한다.
