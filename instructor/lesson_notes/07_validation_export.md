# 7교시 강사 노트

## 전달할 한 문장

검증과 사람의 원본 확인을 모두 통과한 결과만 Excel로 저장한다.

## 시연·운영

- 정상·누락·날짜·금액·합계 오류 다섯 데이터를 순서대로 실행한다.
- 기본 상태 `HUMAN_APPROVED = False`에서 파일 생성이 차단되는지 먼저 확인한다.
- 상호명·날짜·총액을 원본과 대조한 뒤 수강생이 직접 `True`로 바꾸게 한다.
- Excel 수식 문자 보호 구현은 제공 코드로 두고 원리만 한 문장으로 설명한다.

## 복구 지점

검증 오류가 남았으면 값을 수정하고 다시 검사한다. 사람 미승인 상태에서는 완성 복구본을 사용하더라도 Excel을 생성하지 않는다.
