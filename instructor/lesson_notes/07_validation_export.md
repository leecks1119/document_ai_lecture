# 7교시 강사 노트

## 전달할 한 문장

검증 통과와 사람의 원본 확인이 모두 끝난 뒤에만 Excel을 만든다.

## 60분 운영

| 시간 | 행동 | 확인할 결과 |
| ---: | --- | --- |
| 0~10 | 앞 교시 JSON 불러오기 | 입력 출처 |
| 10~22 | 필수값·날짜·품목 계산·합계 검사 | 오류·경고 |
| 22~32 | 승인 전 저장 차단 확인 | Excel 없음 |
| 32~43 | 공개 원본 정답과 품목명 비교 | 수정 후 승인 |
| 43~52 | 3시트 Excel 생성·다운로드 | 파일 경로 |
| 52~57 | Excel을 직접 열어 세 시트 확인 | 요약·품목·근거 |
| 57~60 | 다른 문서 검증 질문 | 8교시 연결 |

## 그대로 말하기

> “검증 통과는 규칙을 통과한 상태이고, 사람 승인은 원본을 확인했다는 별도 기록입니다.”

## 시연할 오류

- 총액 누락
- 수량×단가 불일치
- 품목 합계와 총액 불일치

오류 종류를 늘리기보다 저장이 멈추는 장면을 분명하게 보여 준다.

## 종료 조건

승인 전 차단과 승인 후 `receipt_result.xlsx` 생성을 확인하고, Excel에서
`검토_요약`, `품목`, `원문_근거` 세 시트를 직접 연다.
