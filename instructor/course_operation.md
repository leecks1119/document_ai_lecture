# 강사용 과정 운영안

이 파일은 운영 문서의 입구다. 상세 시간표·전환 기준·말하기 문장은 [마스터 런북](master_runbook.md)을 기준으로 한다.

## 과정 운영의 세 기준

1. 수강생 20명은 모두 1인 1문제·1인 1산출물을 만든다.
2. 같은 공개 한국 영수증을 1~7교시까지 이어 쓴다.
3. 모델 실행보다 `결과 출처 → 원문 근거 → 검증 → 사람 승인 → Excel` 증거를 우선한다.

## 매 교시 확인

- 시작: 이번 산출물 파일명과 정상 화면
- 중간: 초록·노랑·빨강 상태
- 복구: 3분 초과 또는 같은 오류 3명
- 종료: `✅ 실습 완료`와 실제 파일

- API 키·유료 계정·비용 한도
- 강사 실패 시연용 오류 파일
