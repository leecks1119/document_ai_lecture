# 강사용 시연 플레이북

## 시연 원칙

- 먼저 완성 결과를 보여 주고, 그 결과를 만드는 최소 경로만 연다.
- 실제 실행과 준비 결과를 같은 색·같은 문구로 보여 주지 않는다.
- 코드보다 파일명·처리 방식·원문·JSON·검증·승인·Excel을 가리킨다.
- 모든 시연은 저장소의 공개·합성 샘플로 한다.

## 오프닝 7분

### 화면 순서

1. 공개 한국 영수증
2. `ocr_boxes.png`
3. `receipt.json`의 `total_amount`와 evidence
4. 검증 오류 한 건
5. Streamlit 앱의 처리 방식
6. `receipt_result.xlsx` 세 시트

### 말하기

> “오늘은 AI 모델을 구경하는 수업이 아닙니다. 이 영수증 한 장이 검증된 Excel 한 줄이 되는 과정을 여러분 손으로 완주합니다.”

> “화면이 멋져도 업로드한 파일과 결과가 연결되지 않으면 프로토타입이 아닙니다. 파일명, 처리 방식, 원문, JSON이 함께 바뀌는지 보겠습니다.”

## 2교시 영수증 직접 읽기 시연

1. 화면의 `지금 이 사진을 OCR로 직접 읽습니다` 문장을 보여 준다.
2. 3분 타이머를 시작한다.
3. `지금 이 사진을 OCR로 직접 읽었습니다`가 뜨면 bbox와 합계 줄을 가리킨다.
4. 오류가 나면 이유를 읽고 `수업용 예제 결과를 불러왔습니다`와 현재 사진의 결과가 아니라는 문장을 보여 준다.

말하기:

> “복구 결과는 실패를 숨기는 가짜 성공이 아닙니다. 네트워크 문제와 오늘 배울 원리를 분리해 수업을 계속하는 장치입니다.”

## 4교시 실제 VLM 실습

시연 전 확인:

- 공개 비식별 샘플
- Colab T4 GPU
- `paddleocr[doc-parser]==3.7.0`
- API 키를 요구하는 셀이 없음

시연 순서:

1. 입력 이미지
2. `PaddleOCR-VL-1.6` 전체 파이프라인과
   `PaddleOCR-VL-1.6-0.9B` 모델명
3. `model_executed=true`
4. 모델의 실제 Markdown·블록 결과
5. Python 규칙으로 옮긴 업무 JSON
6. 원본 근거와 틀리거나 없는 값의 `null`

5개 좌석 라인을 1분 간격으로 시작한다. 실패 시 준비 결과를 성공으로 보여 주지
않고 GPU 유형과 설치 셀을 전체 화면에서 점검한 뒤 해당 라인만 다시 실행한다.

## 5·6교시 앱 시연

### 5교시

- 파일을 올린다.
- 파일명과 바이트 수가 바뀌는지 보여 준다.
- 준비 결과 버튼을 눌러 화면 뼈대를 확인한다.
- AppTest 통과 뒤 Colab 내부 미리보기에서 같은 버튼을 직접 누른다.

### 6교시

- 업로드 없이 `내 영수증 직접 읽기` 버튼을 눌러 파일 선택 안내를 보여 준다.
- `수업용 예제로 계속하기` 버튼으로 현재 사진을 분석한 결과가 아니라는 안내를 보여 준다.
- 실제 업로드 경로는 `read_receipt_now(uploaded)`가 실행된다는 코드를 한 곳만 보여 준다.
- 실제 OCR 44토큰 기록을 줄바꿈만 했을 때와 공간 순서로 복원했을 때를 비교하고, 후자에서 합계 76,000원·품목 5개가 되는 재검사를 보여 준다.

말하기:

> “오류 화면도 제품의 일부입니다. 자동화가 실패했을 때 무엇을 보여 주고 어디로 보내는지가 실무 품질을 결정합니다.”

## 7교시 승인·Excel 시연

1. `PENDING` 상태에서 Excel이 없는 것을 확인한다.
2. 최종 앱에서 총액을 `999`로 바꾸고 재검증 오류와 다운로드 차단을 보여 준다.
3. 원본 상호명·날짜·품목·총액에 맞게 고치고 검토자·메모를 입력한다.
4. 원본 대조를 체크해 Excel 다운로드가 열리는 것을 보여 준다.
5. Excel의 `검토_요약`, `품목`, `원문_근거`를 연다.
6. `decision`, `reviewer`, `reviewed_at`, `change_reason`을 가리킨다.

말하기:

> “검증 통과는 컴퓨터 규칙을 통과한 상태입니다. 사람 승인은 책임자가 원본을 확인했다는 별도 기록입니다.”

> “사람의 수정도 다시 검증합니다. 이 게이트가 없으면 앱에서 오타를 넣고도 승인 Excel을 만들 수 있습니다.”

## 8교시 형식 비교 시연

- Excel: 셀·수식·병합 제목을 보여 준다.
- Word: 신청서 본문이 텍스트가 아니라 이미지 한 장임을 보여 준다.
- PDF: 텍스트 선택 가능 여부와 한 페이지를 확인한다.
- PPT: 그룹·읽기 순서·발표자 노트가 이미지 캡처에 남지 않는다고 설명한다.
- 표 캡처: 셀 좌표가 사라지고 픽셀만 남는다는 점을 보여 준다.

마무리:

> “우리 회사 문서도 같은 흐름으로 시작할 수 있습니다. 먼저 한 종류, 한 장, 몇 개 필드, 사람 검토가 가능한 범위로 줄이세요.”
