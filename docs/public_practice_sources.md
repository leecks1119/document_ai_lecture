# 내 자료·공개 자료로 실험하는 방법

기준일: 2026-07-29

이 과정은 자료를 많이 모으는 수업이 아닙니다. 제공 예제로 먼저 성공한 뒤
문서 한 장만 바꾸어 “어디까지 되고 어디서 깨지는가”를 확인하는 수업입니다.
실패한 결과도 원인과 다음 질문을 남기면 좋은 실험 결과입니다.

## 가장 쉬운 진행 순서

1. 각 Colab을 제공 예제로 끝까지 실행합니다.
2. 화면에서 `✅ 실습 완료`와 결과 파일을 확인합니다.
3. 아래 목록에서 공개 자료 한 장을 고르거나 개인정보를 가린 내 사진을
   준비합니다.
4. 2교시의 `실습 자료 고르기`에서 다음 중 하나를 선택합니다.
   - `내 컴퓨터에서 업로드`
   - `인터넷 이미지 URL`
5. 상자 이미지와 인식 글자·신뢰도 표를 원본과 비교합니다.
6. 2교시에서 받은 `ocr_result.json`을 3교시에 넣고, 이후 결과도 같은
   방법으로 4교시와 7교시에 이어 넣습니다.
7. 매 교시 마지막 `다른 자료 실험 기록`에 잘된 점·실패한 점·다음 질문을
   한 줄씩 적습니다.

> 인터넷 이미지 URL은 검색 결과 페이지 주소가 아니라 `.jpg`, `.png`,
> `.webp` 같은 이미지 자체의 주소여야 합니다. 웹페이지에서 이미지를
> 내려받은 뒤 `내 컴퓨터에서 업로드`를 선택하는 방법이 더 쉽습니다.

## 교시마다 무엇을 비교할까요?

| 교시 | 다른 자료로 확인할 한 가지 |
| --- | --- |
| 1 | 이 문서에서 OCR·VLM·Document AI가 각각 맡을 일을 구분합니다. |
| 2 | 상자가 글자를 따라가는지, 틀린 글자와 신뢰도를 원본과 비교합니다. |
| 3 | 품목과 표의 같은 행이 하나로 묶였는지 확인합니다. |
| 4 | 필요한 필드가 JSON에 들어갔고 각 값의 원문 근거가 있는지 확인합니다. |
| 5 | 처음 보는 사람이 파일 선택·실행·결과 확인을 혼자 할 수 있는지 확인합니다. |
| 6 | 앱에 문서를 넣어 어느 단계까지 처리되고 어디서 멈추는지 확인합니다. |
| 7 | 일부러 값을 틀리게 바꿨을 때 저장이 막히고, 수정·승인 후 Excel이 만들어지는지 확인합니다. |
| 8 | 이 문서가 작은 PoC에 적합한지, 필요한 필드·검증 규칙·검토자를 정합니다. |

대규모 데이터셋을 내려받을 필요는 없습니다. 수업 중에는 한 장만 골라
실행하고, 원본에서 직접 확인할 수 있는 세 가지 정답을 먼저 적습니다.

## 문서 형식에 따른 입력 방법

| 가지고 있는 자료 | 이 과정에서 시험하는 방법 |
| --- | --- |
| JPG·JPEG·PNG·WEBP | 2교시에 한 장을 직접 업로드합니다. |
| 인터넷 이미지 | 이미지 파일을 내려받아 업로드하거나 이미지 자체 URL을 붙여 넣습니다. |
| PDF | 8교시에서 텍스트 선택 가능 여부를 확인한 뒤 한 페이지를 이미지로 저장해 2교시에 넣습니다. |
| Excel | 셀·수식·병합 구조를 먼저 확인하고, 화면 표를 이미지로 저장해 OCR 결과와 비교합니다. |
| Word | 문단·표가 남아 있는지, 문서 안에 사진만 들어 있는지 먼저 확인합니다. |
| PowerPoint | 도형·표·이미지와 읽기 순서를 확인한 뒤 표 캡처 한 장을 시험합니다. |

## 내 자료를 사용할 때

- 카드번호, 승인번호, 전화번호, 회원번호, 주소, 이름, 서명, 얼굴을 먼저
  가립니다.
- Google Colab도 외부 클라우드입니다. 회사 문서는 조직의 업로드 승인을
  확인합니다.
- Excel·Word·PowerPoint 원본 전체보다 교육에 필요한 표 한 장을 비식별
  이미지로 만드는 방법을 우선 사용합니다.
- 검색 결과에 보인다는 이유만으로 사용하지 않습니다. 원문 페이지,
  이용조건, 작성자·기관을 기록합니다.
- 공개 자료라도 실제 사람의 개인정보가 보이면 사용하지 않습니다.

## 결과를 비교하는 네 줄

```text
자료 이름과 원문 URL:
원본에서 반드시 맞아야 할 값 세 개:
잘된 곳:
틀렸고 업무에서 위험한 곳:
```

좋은 실험 질문은 구체적입니다.

- 사진을 조금 기울이면 합계의 네 점 상자가 글자를 따라가는가?
- 표 캡처에서 품목명·수량·단가가 같은 행으로 복원되는가?
- 신뢰도가 높은데도 원본과 다른 글자가 있는가?
- 신청서의 체크박스와 손글씨는 일반 OCR만으로 충분한가?
- 같은 내용을 Excel 셀에서 읽을 때와 화면 캡처에서 읽을 때 무엇이 사라지는가?

## 사용하지 않는 자료

- 개인정보가 가려지지 않은 개인·회사 문서
- 원문 페이지와 이용조건을 확인할 수 없는 검색 이미지
- 여러 페이지가 섞여 어느 결과가 어느 입력에서 왔는지 알 수 없는 파일
- 원본 정답을 확인할 수 없어 정확성을 비교할 수 없는 자료
