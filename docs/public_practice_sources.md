# 내 사진·공개 자료로 다시 실험하는 방법

기준일: 2026-07-29

이 과정은 제공 샘플로 먼저 성공한 뒤, 입력 한 장만 바꾸어 결과 차이를
관찰하도록 설계했습니다. 자료를 많이 모으는 것이 목적이 아닙니다. 같은
처리 과정을 다른 문서에 적용했을 때 무엇이 잘 되고 어디서 깨지는지 찾는
것이 목적입니다.

## 가장 쉬운 실험 순서

1. 2교시를 제공된 한국 영수증으로 끝까지 실행합니다.
2. 아래 자료 중 하나를 내려받거나, 개인정보를 가린 내 사진 한 장을 준비합니다.
3. 2교시의 `USE_MY_FILE = False`를 `True`로 바꾸고 파일 한 장을 선택합니다.
4. 화면에서 OCR 상자·인식 글자·신뢰도 표를 원본과 대조합니다.
5. `ocr_result.json`을 내려받아 3교시에 넣습니다.
6. 같은 결과를 4·6·7교시까지 이어 사용하고 마지막에 Excel을 내려받습니다.

2교시는 JPG·JPEG·PNG·WEBP 이미지 한 장을 사용합니다. PDF·Excel·Word·PPT는
8교시에서 원본 구조를 비교한 뒤, 표가 보이는 한 페이지를 이미지로 캡처해
같은 OCR 실험에 넣어 봅니다.

[공개 영수증 자료 검토표](public_receipt_datasets.md)에 정리되어 있습니다.

## 내 자료를 사용할 때

- 카드번호, 승인번호, 전화번호, 회원번호, 주소, 서명, 얼굴을 먼저 가립니다.
- 회사 문서는 조직의 외부 클라우드 업로드 허가를 확인합니다. Colab도 외부
  클라우드입니다.
- Excel·Word·PPT는 원본 전체를 올리지 않고, 교육에 필요한 표 한 장을
  비식별 캡처하는 방법을 우선 사용합니다.
- 인터넷 이미지는 “검색 결과에 보인다”는 이유만으로 내려받지 않습니다.
  원문 페이지, 이용조건, 작성자·기관을 확인합니다.

## 한 장 실험 기록

다음 네 줄만 메모하면 자료가 바뀌어도 결과를 비교할 수 있습니다.

```text
자료 이름·출처:
문서 종류와 형식:
OCR가 잘 읽은 곳:
OCR가 틀렸고 업무에서 위험한 곳:
```

좋은 실험 질문은 구체적입니다.

- 사진을 조금 기울이면 합계 상자는 그대로 잡히는가?
- 표 캡처에서 품목명·수량·단가가 같은 행으로 복원되는가?
- 낮은 신뢰도의 글자만 확인하면 중요한 오류를 모두 찾을 수 있는가?
- 신청서의 체크박스나 손글씨는 일반 OCR만으로 처리할 수 있는가?

## 사용하지 않는 자료

- 개인정보가 가려지지 않은 개인·회사 문서
- 원문 페이지와 이용조건을 확인할 수 없는 검색 이미지
- 여러 페이지가 섞여 어느 결과가 어느 입력에서 왔는지 추적할 수 없는 묶음
- 정답을 만들 수 없어 “맞게 읽었는지” 평가할 수 없는 자료
