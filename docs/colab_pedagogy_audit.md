# Colab 실습 교육 적합성 검수

검수일: 2026-07-29  
대상: `master` 배포용 8개 Colab 노트북<br>
수강생 수준: 파이썬을 한 번 사용해 보았지만 문법을 모두 알지는 못하는 일반 실무자

## 검수 결론

8개 실습은 한 장의 한국 영수증을 출발점으로 삼아 `인식 → 구조 복원 →
업무 필드 추출 → 웹앱 → 검증 → 사람 승인 → Excel`까지 이어진다. 각
교시의 결과물이 다음 교시의 입력으로 연결되며, 새 Colab에서 해당 교시만
열어도 공개된 준비 입력으로 독립 실행할 수 있다.

모든 코드 셀은 다음 네 가지를 수강생에게 먼저 알려 준다.

1. 지금 실행하는 실습 단계
2. 이 코드가 사용하는 핵심 변수와 함수
3. 수강생이 직접 바꿀 부분과 그대로 실행할 부분
4. 정상 실행 후 확인할 출력

총 65개 코드 셀 모두에 같은 안내 체계를 적용했다. 수강생은 긴 코드를
처음부터 해석하는 대신 `TODO`가 있는 짧은 값만 수정하고, 출력에서 확인할
근거 한 가지를 찾는다.

## 검수 중 발견해 바로잡은 항목

- 2교시 교재의 ‘세 영역 찾기’와 코드의 판정 기준을 일치시켰다.
- 3·4·7교시는 앞 교시 파일이 없어도 새 Colab의 `전체 실행`이 업로드 창에서
  멈추지 않도록 공개 준비 입력을 기본값으로 정했다.
- 4교시는 준비 입력을 사용했는데도 앞 교시 OCR 결과라고 기록하던 출처 정보를
  실제 입력 경로에 맞게 수정했다.
- 6교시는 앞 교시 런타임에 의존하지 않고 PaddleOCR 설치 여부를 직접 확인한다.
  LIVE 실행이 불가능하면 준비 결과로 계속 학습할 수 있다.
- 8교시는 설명만 있던 업무 문서 확장 코드를 실제 다운로드 ZIP에 포함했다.
