# 수강생 문제 해결

오류가 나면 설치를 오래 붙잡지 말고 다음 순서로 진행합니다.

1. 오류 메시지를 읽습니다.
2. 같은 셀을 한 번만 다시 실행합니다.
3. 전체 시도가 3분을 넘으면 실행을 중지합니다.
4. `준비 결과 사용`을 선택하고 필요한 셀을 위에서 아래로 다시 실행합니다.
5. 계속 실패하면 오류 화면을 닫지 말고 강사에게 알립니다.

## 자주 생기는 문제

| 증상 | 계속하는 방법 |
| --- | --- |
| Python 버전이 다름 | Colab `2026.04` 런타임 선택 |
| OCR 설치·다운로드 지연 | 실행 중지 후 준비 OCR 결과 선택 |
| `5,000원`이 `5,00o원`으로 읽힘 | 원본과 비교해 오류 표시 |
| Streamlit 코드 예외 | 환경 준비 셀 재실행 후 전체 정답과 비교 |
| Streamlit 미리보기가 비어 있음 | 앱 생성 셀 확인 후 미리보기 셀을 한 번 다시 실행 |
| PDF가 열리지 않음 | 승인된 PNG 샘플 한 장 사용 |
| Excel이 생성되지 않음 | 수정값 재검증 오류, 원본 대조, 검토자, 사람 승인 확인 |
| 두 번째 다운로드가 차단됨 | 2교시 ZIP 하나만 내려받고 압축을 해제 |

## 바로 강사에게 알려야 할 때

- 실제 개인정보나 회사 문서를 업로드했습니다.
- 공개 웹앱 주소에 민감한 파일이 보입니다.
- API 키가 셀 출력이나 Git 변경에 보입니다.
- 준비 결과가 실제 처리 결과처럼 표시됩니다.

이 경우 공개 화면을 닫고 Colab 출력과 런타임 파일을 삭제합니다.
