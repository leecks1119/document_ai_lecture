# 문제 해결 가이드

문제가 생기면 설치를 오래 붙잡기보다 같은 학습 목표를 달성하는 mock 경로로 이동한다.

| 증상 | 먼저 확인 | 수업을 계속하는 방법 |
| --- | --- | --- |
| Python 버전이 다름 | 첫 셀의 Python 버전 | Colab `2026.04` 고정 런타임 선택 |
| `pip` 설치 실패 | 네트워크·런타임 상태 | 런타임 재시작 후 1회 재시도, 실패하면 선택 셀 건너뛰기 |
| PaddleOCR 설치·다운로드가 3분 초과 | 실행 시간과 네트워크 | 실행을 중지하고 내장 `MOCK_OCR_RESULT` 사용 |
| PaddleOCR-VL이 느리거나 메모리 부족 | `RUN_PADDLEOCR_VL` | `False`로 두고 내장 `SAMPLE_VLM_MARKDOWN` 사용 |
| `5,000원`이 `5,00o원`처럼 읽힘 | 숫자·문자 OCR 오인식 | 원본과 비교하고 검증 오류를 확인, Excel이 차단됐는지 확인 |
| 한글이 네모로 표시됨 | 이미지 표시용 폰트 | OCR 텍스트 출력으로 값 확인, 실습 계속 |
| Streamlit AppTest가 실패함 | 설치·들여쓰기·변수 오류 | 전체 정답과 비교한 뒤 처리 함수 직접 호출 |
| PDF가 열리지 않음 | 암호·손상·페이지 수 | 제공 비식별 PNG 사용 |
| Excel이 생성되지 않음 | 검증 오류가 남아 있음 | 오류 수정·사람 확인 뒤 다시 생성 |
| Excel 셀이 수식으로 실행됨 | 값이 `=`, `+`, `-`, `@`로 시작 | 제공 수식 실행 방지 함수 사용 |

## 오류를 기록하는 형식

```text
목표:
지금 하려는 작업

실행 환경:
Python 버전, Colab 런타임

실행한 코드:
문제가 난 셀의 짧은 코드

실제 오류:
오류 메시지 전체

기대 결과:
원래 보려던 값

제약조건:
초보자용 코드를 유지하고 새 프레임워크를 추가하지 말 것
```

## 런타임 재시작 기준

다음 경우에만 한 번 재시작한다.

- 패키지 설치가 완료됐지만 import가 계속 실패함
- 이전 셀의 변수나 설치 상태가 뒤섞임

재시작 뒤에는 필요한 셀을 위에서 아래로 다시 실행한다. 전체 시도가 3분을 넘으면 준비 결과 경로로 이동한다.

## 강사에게 바로 알려야 하는 경우

- 실제 개인정보나 회사 문서를 실수로 업로드함
- 공개 웹앱 주소에 민감한 파일이 보임
- API 키가 셀 출력이나 Git 변경에 노출됨
- mock 결과를 실제 처리 결과로 오해할 가능성이 있음
