## 실패 시 우회 순서

1. 오류 메시지를 학습자와 함께 읽는다.
2. 같은 셀을 한 번만 다시 실행한다.
3. 선택 패키지 문제면 mock 경로로 이동한다.
4. Gradio 문제면 함수를 셀에서 직접 호출한다.
5. 해당 교시의 산출물이 생성되면 다음 단계로 진행한다.

mock 사용 사실은 반드시 화면과 설명에서 공개한다.

- PaddleOCR-VL 실제 다운로드와 실행

- 필수값·품목 합계 검증
- 개인정보와 사람의 최종 검토

## 초보자 질문 대응

**“신뢰도가 99%면 맞는 것 아닌가요?”**

신뢰도는 OCR 엔진 내부 신호다. 금액처럼 영향이 큰 값은 원문과 검증 규칙으로 다시 확인한다.

**“준비된 결과면 가짜 실습 아닌가요?”**

1교시 입력은 연락처·거래 식별정보를 가린 공개 한국 실물 영수증이다. 준비된 출력은 개념 차이를 모델 설치 없이 비교하기 위한 교육용 예시이며, 실제 모델 실행 결과처럼 표시하지 않는다.

**“PaddleOCR-VL이 표를 읽으면 값도 정확한가요?”**

아니다. 모델의 Markdown·블록 결과를 업무 JSON으로 바꾸고, 값이 원문과 같은지 별도로 검토한다.

**“왜 실제 회사 문서를 쓰지 않나요?”**

Colab과 Gradio 공유 주소, 외부 API의 데이터 처리 조건을 확인하지 않은 교육 환경이기 때문이다.
