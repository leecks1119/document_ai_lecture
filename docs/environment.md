# 수강생 실습 환경

모든 필수 실습은 Google Colab에서 진행합니다. 로컬 Python, 별도 서버, 생성형 AI API 키, 결제, Google Drive 연결은 필요하지 않습니다.

## 사용할 환경

| 항목 | 수업에서 사용할 값 |
| --- | --- |
| Colab 런타임 | `2026.04` |
| Python | 3.12.x |
| 한국어 OCR | PaddleOCR 3.7.0 + PP-OCRv5 Korean |
| 웹앱 | Streamlit 1.60.0 |
| 기본 하드웨어 | 1~3·5~7교시 CPU, 4·8교시 T4 GPU |

노트북의 첫 번째 셀에서 실제 Python 버전을 확인합니다. 버전이 다르면 **런타임 → 런타임 유형 변경**에서 `2026.04`를 선택합니다.

## 실습할 때 지킬 것

- 식별정보를 가린 공개 샘플 또는 비식별 문서 한 장만 사용합니다.
- 실제 회사 문서와 개인 문서를 외부 API에 보내지 않습니다.
- 공개 Streamlit 터널이나 배포 주소를 만들지 않습니다.
- 수업이 끝나면 Colab의 셀 출력과 런타임 파일을 삭제하고 런타임을 종료합니다.
- 자동 검증용 기록 결과를 실제 모델 실행 결과로 설명하지 않습니다.

## 실행이 3분을 넘을 때

```text
실행 중지
→ 준비 결과 선택
→ 필요한 셀을 위에서 아래로 다시 실행
→ 계속 실패하면 오류 화면을 닫지 말고 강사에게 알리기
```

5·6교시는 Colab 출력 영역의 임시 Streamlit 미리보기에서 직접 조작합니다.
공개 터널이나 배포 주소는 만들지 않습니다. 7교시는 JSON 검증 결과를 보고
오류가 있으면 Excel이 만들어지지 않는지 확인합니다.
