# Document AI와 생성형 AI를 활용한 문서 데이터 추출 및 자동화 실습

> 초급자를 위한 OCR, 생성형 AI, Codex 기반 문서 자동화 미니 앱 제작 실습

## 1. 과정 개요

| 항목 | 내용 |
| --- | --- |
| 교육 시간 | 총 8시간(8교시) |
| 교육 대상 | Python 기초 경험이 있는 Document AI 입문자 |
| 개발 도구 | Codex |
| 실습 언어 | Python 3.12.x |
| UI 프레임워크 | Gradio |
| 실습 환경 | Google Colab `2026.04` 고정 런타임 우선 |
| 최종 결과물 | 문서 업로드부터 CSV 다운로드까지 가능한 Document AI 미니 앱 |

이 과정은 특정 OCR 라이브러리의 사용법보다 문서 자동화의 전체 흐름을 익히는 데 초점을 둔다. 1교시는 연락처·거래 식별정보를 가린 공개 한국 실물 영수증으로 OCR·VLM·Document AI를 구분한다. 이후 교시는 개인정보 없는 합성 영수증으로 JSON 구조화·검증·CSV 저장까지 단계별로 완성한다.

### 핵심 실습 흐름

```text
문서 업로드
    ↓
PaddleOCR 또는 PaddleOCR-VL 선택
    ↓
문서 중간 결과를 업무용 JSON으로 변환
    ↓
필수값·날짜·금액 형식 검증
    ↓
표 확인 및 CSV 다운로드
```

모든 기본 실습은 모델 다운로드나 API 키 없이 실행된다. 실제 PaddleOCR 3.7과 PaddleOCR-VL 1.6 실행은 선택 실습으로 분리한다. 단순한 문서는 OCR, 표와 배치 관계가 중요한 문서는 VLM, 오류 영향이 큰 값은 사람 검토로 연결한다.

## 2. 교육 대상 및 선수 지식

### 교육 대상

- Document AI, OCR, 생성형 AI 기반 정보 추출을 처음 접하는 학습자
- Python 문법과 함수의 기본 개념을 알고 있는 학습자
- 영수증, 신청서, 견적서, 계약서, 점검표 등 반복 문서 업무를 자동화하고 싶은 실무자
- 모든 코드를 직접 작성하기보다 Codex와 협업하여 기능을 만들고 수정하는 방식을 경험하고 싶은 학습자

### 권장 선수 지식

- Python 변수, 조건문, 함수, 리스트, 딕셔너리의 기초
- 터미널에서 명령어를 실행하고 파일을 열어 본 경험
- JSON과 CSV의 용도를 이해할 수 있는 수준의 데이터 기초 지식

OCR, Gradio, 생성형 AI API 사용 경험은 필요하지 않다.

## 3. 학습 목표

과정을 마치면 교육생은 다음을 수행할 수 있다.

1. OCR·VLM·Document AI의 정의와 처리 과정 차이를 설명할 수 있다.
2. 이미지 또는 PDF 문서에 PaddleOCR 또는 PaddleOCR-VL 경로를 선택하고 주요 오류 유형을 확인할 수 있다.
3. 문서의 키-값, 표, 반복 항목 구조를 분석하고 필요한 추출 필드를 정의할 수 있다.
4. PaddleOCR-VL의 Markdown·레이아웃 결과를 JSON 스키마에 맞게 구조화할 수 있다.
5. Codex를 활용해 Gradio 기반 문서 자동화 앱을 구현하고 수정할 수 있다.
6. 추출 결과의 누락값과 형식을 검증하고 CSV 데이터로 내보낼 수 있다.
7. 개인정보, 보안, 오추출 위험을 고려한 사람 중심의 검토 절차를 설계할 수 있다.

## 6. 교시별 상세 운영안

### 1교시. 한국 영수증으로 구분하는 OCR·VLM·Document AI

**목표**

- OCR·VLM·Document AI를 정의하고 입력·처리·출력을 구분할 수 있다.
- 준비된 교육용 예시를 실제 모델 실행 결과와 구별할 수 있다.

**주요 내용**

- OCR: 픽셀 → 텍스트 영역 탐지 → 문자 인식 → 텍스트·좌표·신뢰도
- VLM: 이미지+지시 → 배치·언어 관계 해석 → 표·Markdown·초안 JSON
- Document AI: 입력 품질 → 처리기 선택 → 스키마 → 검증 → 사람 확인 → 저장
- 연락처·거래 식별정보를 가린 2025년 한국 실물 영수증의 출처와 사용 범위

**실습**

1. 같은 한국 영수증에서 OCR·VLM의 교육용 출력 예시를 비교한다.
2. 세 기술의 입력·처리·출력·보장하지 못하는 항목을 정리한다.
3. Document AI의 검증·사람 확인·저장 순서를 배열한다.

**산출물**

- `technology_comparison.json`

### 2교시. OCR 기반 텍스트 추출 실습

**목표**

- 이미지 또는 PDF 입력을 OCR로 처리할 수 있다.
- OCR 실패 시 mock 결과를 사용해 후속 실습을 계속할 수 있다.

**주요 내용**

- OCR의 입력과 출력
- 해상도, 기울기, 노이즈, 글꼴이 인식률에 미치는 영향
- 준비된 OCR 결과의 텍스트·위치·신뢰도 읽기
- 선택 실습으로 PaddleOCR 3.7과 한국어 PP-OCRv5 실행
- 모델 다운로드 실패에 대비한 mock 결과

**실습**

1. 원본 문서와 준비된 OCR 결과를 비교해 오류를 표시한다.
2. 완성된 시각화 함수로 텍스트·위치·신뢰도를 확인한다.
3. 결과 텍스트를 `ocr_text.txt`로 저장한다.

실제 PaddleOCR 실행은 모델 다운로드가 가능한 학습자만 수행하는 선택 실습이다.

**산출물**

- `ocr_text.txt`

### 3교시. 문서 구조 이해 및 추출 결과 정제

**목표**

- 문서를 키-값, 표, 반복 항목 구조로 나누어 볼 수 있다.
- OCR 텍스트를 정보 추출에 적합한 형태로 정리할 수 있다.

**주요 내용**

- 제목, 본문, 표, 서명 등 문서의 구성 요소
- 상호명-값, 항목명-값과 같은 키-값 관계
- 품목 목록처럼 반복되는 데이터 구조
- 줄바꿈, 공백, 잘못 인식된 숫자 등 대표 오류 정제

**실습**

1. OCR 결과에서 문서 영역과 항목의 관계를 표시한다.
2. 불필요한 공백과 줄바꿈을 정리한다.
3. 품목 정보를 행 단위 데이터로 재구성한다.

**산출물**

- 항목 또는 표 단위로 정리한 문서 데이터

### 4교시. PaddleOCR-VL 기반 문서 구조 추출

**목표**

- OCR과 문서 전용 VLM의 차이를 설명할 수 있다.
- 합성 영수증의 JSON 스키마를 읽고 필요한 필드를 설명할 수 있다.
- VLM의 Markdown 중간 결과를 업무용 JSON으로 변환할 수 있다.

**주요 내용**

- PaddleOCR-VL의 제목·문단·표 구조
- 모델 중간 결과와 업무 JSON의 차이
- 합성 영수증의 네 필드 JSON 스키마
- 값이 없을 때 `null` 처리와 원문 근거 확인

**실습**

1. 준비된 VLM Markdown에서 제목·날짜·품목 표·합계를 찾는다.
2. 네 필드의 JSON으로 변환한다.
3. 합성 원본과 날짜·총액을 비교한다.

**예시 결과**

```json
{
  "document_type": "receipt",
  "store_name": "샘플상점",
  "date": "2026-07-27",
  "total_amount": 15000,
  "items": [
    {
      "name": "샘플상품",
      "quantity": 1,
      "price": 15000
    }
  ]
}
```

**산출물**

- `receipt.json`

**주요 내용**

- 흐린 이미지, 손글씨, 복잡한 표, 혼합 문서 등 실패 사례
- 개인정보 최소 수집, 안전한 저장, API 전송 전 확인 사항
- AI 결과를 확정 데이터로 사용하기 전 사람의 검토 절차
- 정확도, 처리 시간, 수정률을 활용한 개선 방법

**실습**

1. 제공된 `run_smoke_test()` 결과를 확인한다.
2. 반복 문서 업무 하나를 고른다.
3. 입력, 필드, 오류 영향, 검토자, 저장·삭제 기준을 한 장의 카드로 작성한다.

**산출물**

- `business_application_card.md`

## 7. 최종 미니 프로젝트

교육생은 다음 기능을 갖춘 문서 자동화 앱을 완성한다.

- 이미지 또는 PDF 업로드
- OCR 실행 및 결과 텍스트 확인
- 생성형 AI 추출용 프롬프트 생성
- 합성 영수증의 mock JSON 결과 표시
- JSON 결과의 표 변환
- 필수값과 날짜·금액 형식 검증
- 검증 결과의 오류·경고 표시
- CSV 다운로드
- OCR 사용이 어려울 때 사용자가 선택하는 mock 모드

### 완료 기준

- 앱 처리 함수와 Gradio 화면을 Colab에서 확인할 수 있다.
- 정상 결과와 검증 오류를 구분하고 오류 결과의 CSV 다운로드를 막는다.
- OCR 설치 실패 시에도 샘플 결과로 3~8교시 실습을 계속할 수 있다.
- 실제 API 키나 개인정보가 코드와 샘플 파일에 포함되지 않는다.
- 교육생이 자신의 업무에 적용할 문서 유형과 검증 절차를 설명할 수 있다.

## 8. 실습 운영 원칙

### Codex 활용

- 요구사항을 한 번에 크게 요청하지 않고 화면, OCR, 추출, 검증, 저장 기능으로 나누어 작업한다.
- Codex가 만든 코드는 교육생이 직접 실행하고 입력과 출력의 관계를 확인한다.
- 오류가 발생하면 오류 메시지, 실행 환경, 기대 결과를 함께 전달해 수정한다.
- 생성된 코드의 API 키, 개인정보, 파일 경로 하드코딩 여부를 확인한다.

### 대체 실습 경로

| 문제 상황 | 대체 방법 |
| --- | --- |
| OCR 라이브러리 설치 실패 | `sample_outputs/ocr_result.txt` 사용 |
| OCR 모델 다운로드 실패 | mock OCR 모드로 전환 |
| PDF 변환 실패 | 동일 내용의 샘플 이미지 사용 |
| PaddleOCR-VL 실행이 느림 | 준비된 VLM Markdown과 mock JSON 사용 |
| Gradio 실행이 어려움 | 동일한 처리 함수를 Colab 셀에서 직접 실행 |
| Codex 사용 불가 | 제공된 시작 코드와 프롬프트 템플릿으로 실습 |

### 과정 범위

이번 8시간 입문 과정에는 대규모 배포, 데이터베이스, 사용자 인증, 모델 학습, React/Next.js 프런트엔드 구현을 포함하지 않는다. 이러한 주제는 미니 앱 완성 후의 확장 방향으로만 소개한다.
