# 2026 Document AI 교재 개편 상태

기준일: 2026-07-27  
작업 브랜치: `document_ai_lecture_2026`

이 문서는 1~8교시 교재, Colab 실습, 이미지 자산의 범위와 완료 증거를 추적한다.

## 범위 원칙

이 과정은 Python 기초 경험만 있는 Document AI 입문자를 위한 8시간 과정이다. 전문 지식을 많이 전달하는 것보다 학습자가 작은 문서 자동화 흐름을 직접 완성하는 것을 우선한다.

교시 하나는 다음 범위를 넘지 않는다.

- 새 핵심 개념 3개 이하
- 기본 실습 1개
- 외부 설치나 API 없이 사용할 mock 대체 경로 1개
- 교육생이 보관할 주요 산출물 1개
- 이해를 돕는 핵심 이미지와 도식만 사용
- 기본 60분 안에 설명, 실습, 정리를 완료

다음 내용은 본 과정의 필수 범위에서 제외한다.

- OCR 엔진 여러 개의 성능 벤치마크와 앙상블
- 모델 학습과 파인튜닝
- 복잡한 표 검출 알고리즘
- 데이터베이스, 인증, 운영 배포
- 대규모 클라우드 아키텍처
- 근거 없는 성능·생산성 수치

## 완료 증거

각 교시는 다음 증거가 모두 있어야 완료로 표시한다.

- 교재 Markdown이 학습 목표, 실습, 기대 결과, 문제 해결, 완료 체크리스트를 포함한다.
- 연결된 Colab 노트북의 기본 경로와 mock 경로가 처음부터 끝까지 실행된다.
- 이미지에는 교육 목적이 있고 대체 텍스트가 작성돼 있다.
- 현재성이 있는 사실에는 2026-07-27 기준 공식 또는 1차 출처가 연결돼 있다.
- 샘플 문서와 출력에는 실제 개인정보가 없다.
- 시니어 교육담당 매니저 검수에서 P0가 없고 총점이 85점 이상이다.
