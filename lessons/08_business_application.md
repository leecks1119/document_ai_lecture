# 8교시. 실무 적용 시나리오 설계 및 최종 정리

> 영수증에서 완성한 다섯 단계가 다른 회사 문서에도 어떻게 재사용되는지 확인하고, 작게 시험할 PoC 후보 하나를 정합니다.
>
> **핵심 메시지:** 영수증의 `입력 → 추출 → 구조화 → 검증 → Excel` 흐름은 견적서·신청서·거래명세서에도 재사용할 수 있으며, PoC는 반복성·입력 품질·오류 영향·검토 가능성을 보고 정해야 합니다.

- 견적서·신청서·거래명세서 중 한 가지를 골라 PoC 적합성을 판단할 수 있다.
- 입력 방식·검토자·저장 결과·중단 조건을 한 장에 정리할 수 있다.

## 4. 핵심 개념

### 4.1 자동화 후보는 처리량만으로 고르지 않는다

- 반복해서 처리하는 문서인가?
- 잘못 추출되면 어떤 문제가 생기는가?
- 사람 판단이 필요한 예외가 자주 생기는가?

반복량이 많아도 오류 영향이 매우 크거나 예외가 많다면 전면 자동화보다 보조 도구가 적합할 수 있다.

### 4.2 데이터가 어디로 가는지 확인한다

Colab 파일은 영구 저장소가 아니며 공개 웹앱 주소는 외부에서 접근될 수 있다. 실제 업무 적용 전에는 다음을 확인한다.

- 필요한 개인정보만 처리하는가?
- 외부 API 전송이 조직에서 허용되는가?
- 누가 결과에 접근하는가?
- 원본과 결과를 언제 삭제하는가?

### 4.3 사람의 승인까지가 업무 흐름이다

> **쉬운 비유**
> Document AI 앱은 신입 사원이고 사람 검토자는 최종 결재자다.

비유의 한계: 모든 값을 사람이 다시 입력하게 만들면 자동화 의미가 없다. 오류 영향이 큰 필드와 예외에 검토를 집중한다.

## 5. 전체 실습 흐름

```text
1~7교시 프로토타입 한 번 실행
  → 영수증의 다섯 단계 확인
  → 견적서·신청서·거래명세서 중 하나 선택
  → 바뀌는 필드·규칙과 PoC 중단 조건 작성
  → poc_candidate_card.md 저장
```

## 6. 단계별 실습

### 실습 1. 한 장짜리 적용 카드 작성하기

먼저 제공된 점검 함수를 한 번 실행한다.

```python
results = run_smoke_test()
assert all(results.values())
results
```

이 함수는 새 코드를 가르치기 위한 것이 아니라 이전 단계가 연결됐는지 확인하기 위한 완성 코드다.

그다음 학습자의 유일한 제작물인 적용 카드를 작성한다.

| 항목 | 예시 |
| --- | --- |
| 입력 문서 | 사내 비용 처리용 영수증 |
| 필요한 필드 | 상호명, 날짜, 품목, 총액 |
| 오류 영향 | 총액 오류 시 정산 금액이 달라짐 |
| 사람 검토자 | 비용 처리 담당자 |
| 저장 형식과 위치 | 승인 후 Excel, 승인된 저장소 |
| 삭제 시점 | 조직의 보존 기준에 따름 |
| PoC 중단 조건 | 식별정보 가림이 어렵거나 수정률이 허용 범위를 넘음 |

**기대 결과**

- `run_smoke_test()` 네 항목이 모두 `True`다.
- `poc_candidate_card.md`에 선택 문서·바뀌는 필드·검증 규칙·중단 조건이 작성된다.

**mock 대체 경로**

앱이나 노트북 실행이 어려우면 제공된 정상·누락·mock 결과 설명을 읽고 카드에서 문제 지점과 검토자를 표시한다.

## 7. 실습 결과 확인

- 견적서·신청서·거래명세서 중 한 가지만 선택했는가?
- 영수증과 달라지는 필드와 검증 규칙을 적었는가?
- 최종 승인자·저장 위치·삭제 기준이 있는가?
- PoC를 계속할 조건과 중단할 조건을 모두 적었는가?

## 8. 문제 해결

| 증상 | 원인 | 해결 방법 |
| --- | --- | --- |
| 점검 결과 일부가 `False` | 이전 단계 오류 | 해당 항목 이름으로 6~7교시 함수 확인 |
| 적용 범위가 너무 큼 | 여러 문서·부서를 한 번에 선택 | 문서 한 종류와 업무 한 단계로 축소 |
| 검토자가 불명확함 | 책임자 미정 | 실제 적용 전 업무 소유자와 승인자 지정 |

## 10. 핵심 요약

- 자동화 후보는 반복성·입력 품질·오류 영향·검토 가능성으로 본다.
- 개인정보·외부 전송·접근·보존·삭제를 확인한다.
- 업무 자동화는 사람의 최종 승인과 수정 절차까지 포함한다.
