> 작은 Streamlit 앱을 직접 엽니다.

## 오늘 만드는 화면

필요한 것은 세 가지뿐입니다.

1. 파일 한 장을 고르는 영역
2. 현재 선택한 원본을 보는 영역
3. 결과를 확인하는 버튼과 JSON 영역

5교시에는 화면 자체에 집중합니다. 실제 OCR 모델 연결은 6교시에서 수행합니다.

## 직접 해보기

### 1. 앱 제목을 정합니다

다음 한 줄만 내 업무에 맞게 바꿀 수 있습니다.

```python
앱_제목 = "문서 한 장 확인 앱"
```

처음 보는 사람도 무슨 문서를 확인하는 화면인지 알 수 있는 제목이 좋습니다.

### 2. 앱 파일을 만듭니다

셀을 실행하면 다음 파일이 만들어집니다.

```text
course_outputs/app_05.py
```

긴 웹 개발 코드를 작성하는 시간이 아닙니다. 제공 코드를 실행하고 제목, 파일
선택, 버튼, 결과 영역이 어떻게 연결되는지를 눈으로 확인합니다.

### 3. 실제 화면을 엽니다

마지막 셀을 실행하면 Colab 안에 Streamlit 화면이 열립니다.

1. 이미지 한 장을 선택합니다.
2. 선택한 원본 이미지가 화면에 나타나는지 확인합니다.
3. `예제 결과 보기` 버튼을 누릅니다.
4. 상호명·날짜·총액 JSON이 표시되는지 확인합니다.

화면의 예제 JSON은 현재 이미지를 모델로 처리한 결과가 아닙니다. 앱에도 이 사실이
표시됩니다. 6교시에서 이 버튼을 실제 PP-OCRv5 함수와 연결합니다.

![최소 웹앱 화면 구성](assets/05/02_minimal_ui.svg)

## 좋은 문서 자동화 화면의 최소 조건

- 사용자가 선택한 파일을 다시 보여 줍니다.
- 버튼이 어떤 작업을 하는지 이름으로 알 수 있습니다.
- 결과가 실제 실행인지 예제인지 구분합니다.
- 오류가 생기면 결과를 꾸며 내지 않고 원인을 보여 줍니다.

## 이번 시간의 정리

앱 코드를 많이 작성하는 것이 목표가 아닙니다. 사용자가 파일을 넣고 원본과 결과를
찾을 수 있는 가장 짧은 흐름을 직접 조작하는 것이 핵심입니다.

## 완료 확인

- 앱 제목을 확인했습니다.
- 파일을 올리고 원본을 확인했습니다.
- 결과 버튼을 직접 눌렀습니다.
- `course_outputs/app_05.py`를 만들었습니다.

다음 교시에는 같은 화면의 버튼에 실제 OCR 모델을 연결합니다.
