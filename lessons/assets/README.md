# 교재 이미지 및 첨부 자료

교시별 교재에서 사용하는 이미지, 다이어그램, 실행 화면을 관리한다.

```text
assets/
├── course_cover.png
├── 01/
├── 02/
├── 03/
├── 04/
├── 05/
├── 06/
├── 07/
└── 08/
```

## 파일 관리 원칙

- 교재 번호와 동일한 폴더에 파일을 저장한다.
- 파일명은 영문 소문자와 하이픈을 사용해 내용을 알아볼 수 있게 작성한다.
- 실제 개인정보, API 키, 사내 기밀이 표시된 화면은 저장하지 않는다.
- 저장소 용량을 고려해 이미지는 필요한 크기로 최적화한다.
- 교재 Markdown에서는 상대 경로로 파일을 참조한다.

## 재생성 방법

교시별 SVG 도식 16개는 다음 명령으로 다시 만들 수 있다.

```bash
python tools/generate_lesson_diagrams.py
```

SVG는 개념 관계와 한글 문구를 정확하게 유지하기 위한 코드 기반 교육 도식이다.
